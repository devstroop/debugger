# Support

## Community Support

- **Issues:** Use the [GitHub issue tracker](https://github.com/devstroop/debugger-mcp/issues)
  for bug reports and feature requests.
- **Discussions:** Start a [GitHub Discussion](https://github.com/devstroop/debugger-mcp/discussions)
  for questions, ideas, or general help.

## Before Opening an Issue

1. Check the [README](README.md) for configuration and usage.
2. Search existing [issues](https://github.com/devstroop/debugger-mcp/issues)
   — yours may already be reported.
3. Run with `DEBUGGERMCP_LOG=debug` and include the logs.

## Scope

Support is limited to the debugger-mcp server itself. Issues with:
- codelldb (report [upstream](https://github.com/vadimcn/vscode-lldb))
- OpenCode, Cline, Roo, or other MCP clients
- Your specific debug target (C, Rust, Zig program)

are best addressed by those respective communities.

## Commercial Support

For commercial support enquiries, contact the maintainer via the
[GitHub repo's About section](https://github.com/devstroop/debugger-mcp).
